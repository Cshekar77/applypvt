Tips for a Smooth Import

Follow these guidelines to avoid errors during import.

  • Make sure the first row of your Excel file contains column headers
  • Each student must have a unique email address
  • Date of birth should be in DD-MM-YYYY or DD/MM/YYYY format
  • Category names should match exactly: General, SC, ST, OBC, EWS, PWD
  • Percentage can be auto-calculated if you provide Total Marks and Obtained Marks
  • Students already in the system (same email) will be skipped, not duplicated
  • All imported students will be marked as email-verified automatically
