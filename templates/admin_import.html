Upload Excel File

Upload your .xlsx or .xls file containing student data. We'll read the column headers and let you map them.

How it works: Upload any Excel file → We detect your column names → You map them to our fields → We import the data and auto-create student accounts.

Required columns in your Excel file:
  • Email Address — Student's email (used as username)
  • Candidate Name — Full name of the student
  • Date of Birth — Used as password (format: DD-MM-YYYY)

Optional but recommended: Mother's Name, Father's Name, Category, 10th/12th details, etc.

Password: Each student's password will be their Date of Birth (e.g. 15-08-2001 → 15082001).

Click to choose file or drag & drop

Tips for a Smooth Import

Follow these guidelines to avoid errors during import.

  • Make sure the first row of your Excel file contains column headers
  • Each student must have a unique email address
  • Date of birth should be in DD-MM-YYYY or DD/MM/YYYY format
  • Category names should match: General, SC, ST, OBC, Cat-I, 2A, 2B, 3A, 3B
  • Yes/No fields accept: Yes/No, True/False, 1/0
  • Percentage can be auto-calculated if you provide Total Marks and Obtained Marks
  • Students already in the system (same email) will be skipped, not duplicated
  • All imported students will be marked as email-verified automatically
  • After import, you'll need to verify students and assign ranks manually
